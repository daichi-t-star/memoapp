# memo. 2.0

文章・画像・ファイルをまとめる、日本語のメモアプリ。入力した文章はそのまま保存され、Markdownの記法や編集・プレビューの切り替えは不要です。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

開発: `http://127.0.0.1:5173/memoapp/` / 公開用ビルドのプレビュー: `http://127.0.0.1:4173/memoapp/`

## 使い方

- 「新しいメモ」で作成。タイトル・本文・タグ・フォルダは端末内に自動保存。
- 写真を貼り付け、ファイルをドロップ、または「画像」「ファイル」から複数添付。1ファイル20 MBまで。画像をクリックすると拡大、ファイルは元の名前でダウンロード。
- 検索はタイトル・本文・タグ・フォルダ・添付名が対象。スペース区切りで絞り込み。`⌘/Ctrl + K` で検索。
- ピン留め、アーカイブ、ごみ箱に対応。ごみ箱のメモは復元可能。
- 設定から、以前と同じGitHubの保存先を選ぶと旧メモを取り込む。保存済みの旧接続設定は自動で引き継ぐ。
- 「この端末専用」と各GitHubリポジトリ・ブランチのデータは別々。端末専用メモを別の保存先へ移す場合は、バックアップを書き出し、切り替え先で復元する。
- バックアップはメモと添付の実体を含むJSON。GitHub上の未取得添付はオンラインで取得してから書き出す。不足があれば不完全なバックアップを作らずエラーを表示する。復元は既存メモを上書きせず、新しいコピーとして追加する。

## 保存と同期

- IndexedDB `memoapp-v2` の `notes` と `files` に保存。メモと添付は同一トランザクションで保存し、失敗時は両方をロールバックする。
- 画面は端末内データから表示。GitHubの接続確認や取得完了を待たずに編集できる。前回開いたメモも復元する。
- 接続直後・編集後・オンライン復帰時・表示中60秒間隔で同期。ファイルのGit SHAで差分を判定し、未変更の本文・更新履歴を再取得しない。
- 本文と添付をGit blobs/tree/commitでまとめてから、`force: false` でブランチを更新する。失敗してもローカルの変更は未同期のまま保持。成功応答を受け取れなかった場合は、次回同期で内容を照合する。
- 同時編集は、GitHubの版と「この端末の変更」のコピーを両方残す。同期中の追加入力は次回の同期待ちとして保持する。
- GitHubを直接操作して削除された新形式メモはローカルのごみ箱へ。ローカル未同期編集があればコピーに保護する。
- 新形式は `.memoapp/notes/<id>.json`、添付は `.memoapp/attachments/<uuid>/<filename>`。通常の文章・メタデータ・添付参照を保存する。
- 旧 `.md` は読み取り専用で取り込む。見出し・表・箇条書きは文章に、画像や添付は別の添付欄に変換。編集時は新形式のファイルを作り、元の `.md` を削除・上書きしない。
- 旧メモの更新日は履歴を全件取得しないため「以前のメモ」と表示。新形式で編集すると更新日時が記録される。新形式へ編集済みのメモは旧形式の変更を追従しないため、移行後は新アプリから編集する。
- 初回表示後、公開用ビルドは静的ファイルをService Workerにキャッシュ。GitHubの認証付きレスポンスはService Workerでキャッシュしない。未取得のメモや添付には接続が必要。
- ブラウザのデータを消すと、未同期のメモ・端末専用のメモも消える。GitHub同期またはバックアップで別の保存先に保持する。外部URLの画像はバックアップでもURL参照として保持する。

## 検証

`npm test` で17項目の回帰テストを実行。端末保存、同時編集、添付のバイト保持、20 MB制限、旧メモ移行、バックアップ復元、通信失敗、成功応答消失、容量不足時の再保存を含む。

ブラウザでは日本語入力・タグ・ファイル選択からの画像/ファイル添付・再読み込み・画像表示・320/390px幅の横はみ出しを確認。

2026-09-06、利用者の承認後に `tests/github-live.ts` でGitHubとの結合テストを実施。アプリ本体のリポジトリに一時ブランチを作り、テスト専用画像・1.1 MBのダミーファイル・日本語のテスト文で、原本とのバイト一致、別端末読み込み、未変更本文の取得ゼロ、同時編集の両方の保存を確認した。個人メモのリポジトリは変更せず、テスト用ブランチは削除済み。

実同期テストを再実行する場合は `node --import tsx tests/github-live.ts`。GitHub CLIの認証を利用し、アプリ本体のリポジトリに一時ブランチを作成・削除する。
